# Casa de Pinheiro

Página estática em português para o Pinheiro Canadense de Natal Greycom. O projeto inclui a galeria, a ficha técnica, os dados da oferta consultada e avaliações. O botão de compra encaminha para o anúncio original do vendedor.

## Executar localmente

Na raiz do repositório, use um servidor de arquivos estáticos. Com Node.js, rode:

    npx serve .

O projeto usa HTML, CSS e JavaScript e não precisa de variáveis de ambiente. A galeria e as fontes principais estão em assets/. Os preços e as condições de entrega correspondem à captura que deu origem à página.

## Publicar na Vercel

Importe o repositório como projeto estático e use a raiz do repositório. O arquivo vercel.json já define a configuração.
